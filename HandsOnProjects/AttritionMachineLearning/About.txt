This notebook shows a machine-learning workflow for predicting employee attrition. It loads an HR dataset, prepares the data by separating features and the target (whether an employee leaves), encodes categorical variables, and splits the data into training and testing sets. A Random Forest classifier is then trained to learn patterns related to attrition and used to make predictions, allowing the model’s performance to be evaluated. Overall, it demonstrates how ML can be used to analyze workforce data and anticipate employee turnover
